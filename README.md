# Адреса R2 RAGE Launcher

Единая публичная конфигурация: **[launcher-links.json](launcher-links.json)**.

Лаунчер загружает её при каждом запуске:
`https://raw.githubusercontent.com/Dzhet225/APILINK/main/launcher-links.json`.
Измените JSON, сохраните изменения в ветке **main**, затем перезапустите лаунчер.
Для смены адресов пересборка уже обновлённого лаунчера не нужна. GitHub может
отдавать предыдущую версию ещё несколько минут из своего кэша.

Текущий файл настроен на **PROD_DEV**: TLS API 8762, HTTPS API/страницы8761,
CDN6768. Это тестовая конфигурация; все лаунчеры с этим источником получают её.
Для одновременного выпуска production и test нужны отдельные JSON/источники
в соответствующих сборках. Поле environment — подпись конфигурации, оно не
переключает NODE_ENV работающего серверного API.

| Раздел | Что настраивает |
| --- | --- |
| `api.host`, `api.tlsPort` | TLS-соединение лаунчера с API: логин и команды |
| `api.httpsBaseUrl` | Базовый HTTPS-адрес API |
| `pages` | Полные адреса вкладок: информация, новости, события, обновления, топ, аукцион, безопасная торговля |
| `cdn.r2pvp_default` | Корень обновлений1602, без `/manifest` или `/chunks` в конце |
| `cdn.r2rage_1703` | Корень обновлений1703 |
| `launcherUpdates.windows` | Корень Squirrel-обновлений лаунчера; `/x64` или `/ia32` добавляется автоматически |
| `external` | Форум, пополнение баланса, сайт, Discord, страница скачивания лаунчера |
| `legacy` | Прежние HTTP LApi/LApi2; оставлены для совместимости старых модулей |

Для API указывайте имя хоста без схемы/порта в `host` и числовой `tlsPort`.
Для остальных полей — полный URL. HTTPS обязателен для страниц, API и внешних
кнопок. CDN и legacy допускают HTTP. Логины/пароли в URL, query-параметры и
фрагменты запрещены. Страница профиля форума строится от `external.forum`.
Адреса в pages независимы: при переносе всех страниц поменяйте каждый из них
вместе с `api.httpsBaseUrl`. Сертификаты TLS/HTTPS должны соответствовать хостам.

**Никаких паролей, токенов форума, сессий, ключей API и настроек баз данных.**
Этот репозиторий публичный. Авторизация добавляется лаунчером только во время
работы; она не сохраняется в этом JSON.

## Как применяется

1. Лаунчер запрашивает JSON до подключения к API и создания окна авторизации.
2. Проверяет формат целиком. Ошибочный или неполный JSON не применяется частично.
3. Сохраняет корректную копию в `metadata/launcher-links.json` своего userData.
4. При недоступности GitHub использует последнюю корректную копию. При первом
   запуске без копии — адреса, встроенные в сборку. Ожидание GitHub ограничено7с.
5. Все окна получают одну конфигурацию на запуск. Во время активной сессии
   адреса не меняются; для применения изменений нужен перезапуск.

Для1602/1703 поле updateUrl из серверного каталога больше не переопределяет
этот JSON. Поэтому менять LAUNCHER_*_CDN в API для новых лаунчеров не нужно.
Старые лаунчеры ещё читают серверный каталог: эти поля пока следует сохранять.
Игровые аккаунты, разрешение запуска1703, хост/порт игрового сервера и подключение
к БД по-прежнему управляются серверным API. Этот файл не включает игровые серверы.
Динамические ссылки/картинки внутри новостей приходят с форума через API.

Автообновление поддерживается установленным Squirrel-лаунчером начиная с 2.1.7.
Первую версию с этим механизмом нужно установить вручную. Раздел `launcherUpdates`
необязателен: без него проверка выключена. Версию в JSON указывать не нужно:
CDN отдаёт её в `RELEASES`. Новые пакеты публикуются командой `launcher:publish`
в проекте CDN; подробный порядок — `Louncher/LAUNCHER_AUTOUPDATE_RU.md` в рабочей копии.

## Разработка

После первого внедрения требуется один раз собрать и распространить новый
лаунчер. Его резервный JSON находится в
`ClientApi/R2PvP_Launcher/src/shared/launcher-links.defaults.json`.
При выпуске новой сборки обновляйте резервную копию из этого файла; обычная
смена ссылок в GitHub не требует сборки.
В логах лаунчера `Public launcher links loaded` показывает источник:
`github`, `cache` или `bundled`.
